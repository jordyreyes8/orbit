# Orbit

Orbit is a personal AI operating system backed by OpenClaw.

It is designed to capture, organize, remember, and act across personal memory, tasks, finance, email, travel, projects, and system intelligence.

## Current Phase

Phase 0 — Foundation

Goal: get the Orbit backend repo initialized with a basic FastAPI app, Docker setup, and environment configuration.

## Tech Stack

- Python
- FastAPI
- Postgres
- Docker
- OpenClaw for agent/runtime workflows
